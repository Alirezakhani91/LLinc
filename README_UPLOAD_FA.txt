LANDMARK LIVING — GitHub Pages staging package

تمام فایل‌های این ZIP را در پوشهٔ ریشهٔ مخزن قرار بدهید؛ نباید index.html داخل یک پوشهٔ اضافه باشد.
در GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save
یا با GitHub Desktop، فایل‌های استخراج‌شده را در local repository کپی کنید، Commit و Push بزنید.

این نسخه برای تست staging است؛ پشتیبانی ارسال فرم Webflow روی GitHub Pages بدون سرویس فرم جداگانه برقرار نیست.
فونت‌های Giveny و Google Fonts از URLهای سایت اصلی دریافت می‌شوند و برای اجرای کامل به اینترنت نیاز دارند.
قبل از تغییر دامنهٔ اصلی، منوی موبایل، اسلایدرها، اولین لود مرورگر و صفحات را تست کنید.
